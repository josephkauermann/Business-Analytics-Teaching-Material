# Business Analytics Case Study — Global Bike Inc.

Welcome to the practical case study on Data-Driven Business Decision-Making. In this project, you will work with real SAP ERP data to solve two core business analytics use cases: **Customer Lifetime Value (CLV) Prediction** and **Customer Segmentation**.

The case study follows the **CRISP-DM** (Cross-Industry Standard Process for Data Mining) framework and guides you through the entire data mining lifecycle — from raw data to actionable business insights.

## Repository Structure

```
├── Business_Analytics_Case_Study.ipynb   # Interactive Jupyter Notebook (Exercises)
├── Business_Analytics_Case_Study.md      # Markdown export (for AI Tutor context)
├── Companion_PDF.pdf                     # Theoretical reference & cheat sheets
├── Setup.pdf                             # Step-by-step environment setup guide
└── assets/                               # Upload this folder's contents to Watsonx
    ├── KNA1.csv                          # Customer Master Data
    ├── KNVV.csv                          # Customer Sales Data
    ├── VBAK_messy.csv                    # Sales Orders (with artificial data quality issues)
    ├── VBAP.csv                          # Sales Order Items
    └── silhouette_examples.png           # Visualization asset
```

## Getting Started
1. Download this repository as a ZIP file and extract it on your local computer.
2. Open the **Setup PDF** and follow the step-by-step instructions to configure your IBM Watsonx.ai environment.
3. Keep the **Companion PDF** open locally — the notebook will frequently reference it for theoretical background and cheat sheets.
